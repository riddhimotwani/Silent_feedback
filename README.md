# 🎓 Silent Class  
### Anonymous Feedback System for College Lectures  

Silent Class is a web-based platform that enables students to share **honest, anonymous feedback** about lectures and teaching quality. It removes social pressure and provides institutions with **data-driven insights**.

---

## 🚀 Features  

- 📝 **Anonymous Feedback Submission**
  - No login required  
  - No personal data collected  
  - Per-lecture feedback  

- 📊 **Admin Dashboard**
  - Total reviews & sentiment stats  
  - Interactive charts  
  - KPI cards (Positive, Neutral, Negative)  

- 🔍 **Search & Filter**
  - Filter feedback by sentiment  
  - Keyword-based search  

- 🤖 **AI Sentiment Analysis**
  - Automatically classifies feedback  
  - Handles natural language  

- 🌗 **Dark/Light Mode**
  - Mobile-first responsive design
